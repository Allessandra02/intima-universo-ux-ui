## 📌 Sobre o Projeto

**Íntima Universo** é um projeto acadêmico de UX/UI Design desenvolvido para a disciplina de Interface/Prototipagem do curso de Análise e Desenvolvimento de Sistemas (Unicid). A proposta é uma plataforma de **gestão jurídica** voltada a advogados, com foco na captura automatizada de intimações e publicações expedidas pelos Diários de Justiça Eletrônicos (DJEs) em todo o território nacional.

O objetivo do sistema é reduzir o retrabalho manual dos operadores do direito, centralizando o acompanhamento processual, o cálculo de prazos e a gestão de documentos em um único painel.

> 👩‍💻 Projeto desenvolvido em dupla por **Alessandra Guimarães da Silva** e **Valquiria Rodrigues de Macedo**.

## 🎯 Funcionalidades (Requisitos Funcionais)

- Painel de controle exclusivo do advogado (área logada)
- Leitura automatizada de Diários Oficiais por nome/OAB do advogado
- Monitoramento de andamento processual com sincronização a tribunais (PJe, e-SAJ)
- Central de intimações lidas/não lidas
- Cálculo automático de prazos com base no CPC/2015
- Notificações via WhatsApp/E-mail
- Repositório de documentos por processo
- Busca unificada por processo, partes ou tribunal

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Figma** — prototipação de telas e fluxo de navegação
- **BPMN** — modelagem do fluxo de processos de negócio
- Levantamento de Requisitos Funcionais (RF) e Não Funcionais (RNF)
- Mapa mental para organização conceitual do sistema

## 🔎 Processo de Design

O projeto seguiu as seguintes etapas:

1. **Levantamento de requisitos** — definição de objetivo, escopo e diferencial competitivo
2. **Modelagem de processos** — fluxograma BPMN do funcionamento do sistema
3. **Mapa mental** — organização das funcionalidades e relações entre módulos
4. **Especificação de telas** — Landing Page, Login, Dashboard e Detalhes do Processo
5. **Fluxo de usuário (User Flow)** — do primeiro acesso até o uso recorrente da plataforma
6. **Prototipação no Figma** — telas navegáveis e clicáveis
